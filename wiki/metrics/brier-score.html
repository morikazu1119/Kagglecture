Brier Score

Brier Scoreは、予測した確率と実際の0/1結果のズレを二乗して平均するMetricです。「勝つ確率70%」のように、classだけでなく確率そのものの質を評価したいときに使います。

Binary classificationでは0が完全一致で、小さいほど良い指標です。2026年のMarch Machine Learning Maniaでは公式Metricとして使われました（Competition公式）。

式

Binary classificationでは、各sampleの正解 y を0または1、positive classの予測確率を p とすると、Brier Scoreは次の平均二乗誤差です。

\[ BS = \frac{1}{N}\sum_{i=1}^{N}(y_i-p_i)^2 \]

scikit-learn公式ドキュメントでも、Brier Scoreはprobabilistic predictionに対するstrictly proper scoring ruleとして定義されています。Binary版は通常0〜1で、小さいほど良い値です。

LogLoss・Accuracy・AUCとの使い分け

Metric何を見るか確率の大外し向く場面
Brier Score確率と0/1結果の二乗距離二乗で罰するforecast・calibrationを含む確率品質
LogLoss正解classへ置いた確率0/1付近の誤答を非常に強く罰する確率分類全般
Accuracythreshold後の正誤確率差を見ない最終classだけ重要
ROC-AUCpositiveを上へ並べる順位確率scaleを直接見ないranking能力が重要

Brier Scoreはcalibrationに敏感ですが、Brierが低いこととcalibrationだけが良いことは同義ではありません。scikit-learnはBrier lossがcalibration lossとrefinement lossに分解でき、refinementも独立して変化すると説明しています（Model evaluation）。Calibration自体を調べる場合はProbability Calibrationも確認します。

Kaggleでの実例

March Machine Learning Mania 2026 — 1位

公式Competitionは勝敗確率をBrier Scoreで評価しました（公式ページ）。1位解法は最終0.1097454、1位 / 3,485 teamsと報告しています（1st Place Solution）。

この解法ではLeave-One-Season-Out系のValidationでIsotonic calibrationを行い、CV BrierがMen 0.1850→0.1822、Women 0.1390→0.1357、Total 0.1620→0.1590へ改善しています。Brierを目的関数として、確率のcalibrationをOOFで検証した具体例です。Evidence A。

March Machine Learning Mania 2026 — 2位

2位解法はXGBoost 60% + Logistic Regression 40%のensembleで、最終Brier 0.1149886を報告しています。予測を[0.02, 0.98]へclipし、極端に外したときのBrier penaltyを抑える設計を採用しています（2nd Place Solution）。ただしclip幅そのものの独立ablationは示されていないため、この採用実績はEvidence Bとして扱います。

WiDS Global Datathon 2026

WiDS Global Datathon 2026では、評価の70%にcensor-awareなWeighted Brier Scoreが使われ、24h / 48h / 72hの予測を0.3 / 0.4 / 0.3で重み付けしています（Competition評価仕様）。Brier系Metricが単純なbinary forecastだけでなく、time horizon別のrisk predictionにも使われる例です。
