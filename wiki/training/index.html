Training

Trainingは、「モデルをどう学習させるか」に関する手法です。

同じarchitectureでも、停止条件・weight averaging・入力変換・loss・target regularization・pretraining・feature encodingで結果は大きく変わります。ここでは何を変える手法かで分けます。

学習を止める・安定させる

Early Stopping

Validation改善が止まった時点で学習を止め、best checkpointを使う。

Exponential Moving Average (EMA)

学習中のweightを指数移動平均し、更新ノイズをならした別weightを評価・推論に使う。

Stochastic Weight Averaging (SWA)

学習後半の複数weightを等重みで平均し、1つの安定した推論weightを作る。

入力を増やす・混ぜる

Data Augmentation

targetを保つ変換で学習sampleを増やし、不要な変化への過適合を抑える。

Mixup / CutMix

sampleとlabelを混ぜて中間sampleを作るstrong augmentation。

Synthetic Data / Procedural Synthesis

simulation・生成規則・既知素材からtarget-domainに近い学習sampleを作り、label不足やdomain gapを埋める。

Loss・Targetを調整する

Focal Loss

easy sampleのlossを抑え、hard exampleへ学習を集中させる。

Label Smoothing

one-hot targetを少し平らにし、分類modelの過度な確信やlabel noiseへの過適合を抑える。

Feature Representation / Encoding

Aggregation Features

entity・category・履歴をcount / mean / std等で集約し、1行だけでは見えないgroup contextを特徴量化する。

Frequency / Count Encoding

categoryや離散値を出現回数・割合へ変換し、rare / commonという1列のsignalを追加する。

Lag / Rolling Features

過去の値と過去windowの統計を列へ変換し、自己相関・周期・局所trendをtabular modelへ渡す。

Target Encoding

categoryごとのtarget統計をfeature化する。fold内計算によるLeakage対策が必須。

Pretraining / Transfer

Pretraining / Transfer Learning

大規模・関連taskのpretrained weightをCompetitionへ転移する。
