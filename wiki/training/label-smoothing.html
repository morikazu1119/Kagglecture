Label Smoothing

Label Smoothingは、分類の正解labelを「正解=1、その他=0」と断定せず、少しだけ確率を他classへ分ける正則化です。

モデルに「100%確実だ」と学習させにくくすることで、over-confidenceやlabel noiseへの過適合を抑えます。ただし常に精度が上がる手法ではなく、smoothing量はOOF / Validationで比較します。

仕組み

通常の3-class分類で正解がclass Aならtargetは [1, 0, 0] です。Label Smoothingはこれをuniform distributionと混ぜます。PyTorchの定義では、smoothing係数を ε、class数を K とすると、targetは (1-ε) × one-hot + ε/K になります（PyTorch CrossEntropyLoss）。

模式例: 3-class、正解=A。実測値ではありません。

ε=0.10では、正解classだけを1.0へ押し切る圧力を弱めます。

Label Smoothing RegularizationはSzegedyらのInception研究で導入され、その後、分類modelのconfidenceや表現への影響が研究されています（Szegedy et al., 2015）。

Kaggleでの実例

RSNA Screening Mammography Breast Cancer Detection — 1位

1位解法は通常のlabel smoothingと、positiveだけを弱めるsoft positive labelを比較しています。fold 0の実験では通常の label_smoothing=0.1 がbest PF1 0.4970、positive targetを0.8にした設定が 0.5714 でした。一方、後日の全体ablationではsoft positive labelが標準label smoothingを明確に上回るとは確認できないと報告されています（1st place solution）。局所foldの改善だけで一般化を断定しない好例です。Evidence A。

同じwriteupでは、external dataなし・label smoothing 0.1でOOF F1 0.4921 / Private 0.53、external dataありではOOF F1 0.5161 / Private 0.56 と報告されています。ここで改善の主因はexternal dataであり、label smoothing単独の効果量として解釈してはいけません。

Anime Gender Classification 2026 — 31位

2026年6月の公開Writeupでは、pretrained ResNet50、strong augmentation、cosine warmup、15-fold soft votingとともにLabel Smoothingを最終pipelineへ採用しています（solution writeup）。単独ablationは公開されていないため、採用実績としてEvidence BではなくD相当に留め、効果量は推測しません。

注意点

  • εを大きくしすぎない: targetを平らにしすぎるとclass間の識別signalまで弱めます。固定値を慣習で入れずValidationで比較します。
  • Calibration改善と同義ではない: confidenceを抑える効果があっても、目的metric上のcalibrationが必ず改善するとは限りません。
  • Mixup / CutMixとの重複を確認する: これらもsoft targetを作るため、同時利用時は追加smoothingが強すぎないかablationします。
  • binary / multi-labelでは実装定義を確認する: softmax multi-classのuniform mixingと、BCEでpositive / negative targetをずらす実装は同一ではありません。
  • Public LBでεを選ばない: OOF / Validationで候補を比較し、fold間で傾向が安定するか確認します。

Quick Reference

まず試す

Cross Entropy分類でover-confidenceやlabel noiseが疑わしいとき、小さいεからOOF比較。

比較する

ε=0を必ずbaselineに残し、Focal Loss、class weight、Mixup / CutMixとも目的を分けて比較。

採用判断

単一foldやPublic LBではなく、OOF metric・fold安定性・確率分布を確認。
